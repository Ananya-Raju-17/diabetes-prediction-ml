# Diabetes Prediction using Machine Learning

## Project Overview
This project predicts whether a person is likely to have diabetes using machine learning algorithms.  
The model analyzes multiple health indicators and classifies patients as diabetic or non-diabetic.

## Problem Statement
Diabetes is a common health issue affecting millions of people worldwide.  
Early prediction can help doctors and patients take preventive actions.

## Dataset
Dataset used:
diabetes_health_indicators.csv

The dataset includes several health related attributes such as:
- BMI
- Age
- Blood Pressure
- Cholesterol
- Physical activity
- Smoking habits
- General health indicators

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithms Used
This project compares multiple classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Support Vector Machine (SVM)
- Gradient Boosting

## Project Workflow
1. Import Dataset
2. Data Preprocessing
3. Feature Scaling
4. Train/Test Split
5. Model Training
6. Model Evaluation
7. Accuracy Comparison

## Output
The program trains multiple machine learning models and compares their prediction accuracy.

Example:

Random Forest : 89%  
SVM : 87%  
Logistic Regression : 85%
